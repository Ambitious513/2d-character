1. What the project is
Ambitious513/2d-character is Stride, version 2.2.0: a reusable, frame-deterministic 2D character and environment kit for Remotion, plus a live visual studio built on top of it.
It is not just a demo animation. It is intended to be a small library that other Remotion projects can consume:
6 cast members: Milo, Ada, Kwame, Juno, Ravi, Pip.
10 motions: walk, run, idle, wave, talk, jump, sit, point, think, dance.
7 emotions.
Wardrobe depth: hair styles, outfits, builds, accessories.
Deterministic lip-sync and dialogue timing.
4 environments: street, park, room, backdrop.
3 lighting passes: day, golden, night.
Alpha-ready export recipes: PNG sequence, ProRes 4444, VP9 WebM, opaque MP4.
A visual studio with live <Player> preview, presets, timeline, export dialogs, component browser, and keyboard shortcuts.
The core value proposition is: same settings + same frame + same fps = same SVG output, so renders are stable, testable, and compositable.

3. Architecture and constraints that matter
The project has a clear layered architecture:
text
src/ui + src/App.tsx     visual studio app, not exported
src/remotion             compositions + factories, exported
src/rig                  core library, exported
src/index.ts             only public import surface
The most important invariants are:
The render path must stay deterministic.
No Math.random(), Date.now(), wall-clock time, useId(), or mutable module counters in rendering logic.
SVG IDs must use stableId(), not useId().
This was a real historical bug: multiple independently rendered characters collided on gradient IDs, causing every character to inherit the first character’s jacket color. The fix is now guarded by tests.
src/index.ts is the only public API barrel.
The studio UI must not leak into the library surface. There is a packaging test enforcing this.
Presets are versioned.
Current preset schema version is 2. There is backward compatibility from v1, especially environment → timeOfDay.
Alpha exports require PNG image format.
The Remotion config defaults to JPEG, which has no alpha. Alpha recipes must pass --image-format=png.
Real source must be committed, not tarballs.
The repo history shows previous work was lost or obscured by tarball uploads. PROGRESS.md explicitly warns future agents not to repeat that.
